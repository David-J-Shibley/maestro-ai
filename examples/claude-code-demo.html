What Claude Code Can Do

An agentic coding assistant that lives in your terminal. It reads your codebase, plans multi-step work, runs commands, edits files, and ships features — all from natural language.

Core capabilities

Click a tab to see how each one works — with a representative code snippet.

📄

Read & edit across files

Claude Code reads files, understands the surrounding patterns, and makes precise edits — matching your existing style.

// Reads auth.ts, then patches the login handler
Read(file_path="src/auth.ts", offset=42, limit=30)
Edit(file_path="src/auth.ts",
     old_string="return token",
     new_string="return sign(token, SECRET)")
⚡

Run shell commands

Executes commands, reads output, and acts on failures — tests, builds, git, anything in your shell.

Bash(command="npm test -- --coverage")
# → 42 passed, 0 failed
# → coverage: 87.3%
Bash(command="git checkout -b fix/login-token")
🔍

Search the codebase

Finds symbols, usages, and patterns fast — across thousands of files — without you opening an editor.

Grep(pattern="processPayment", output_mode="files_with_matches")
# → src/checkout/service.ts
# → src/checkout/refund.ts
# → tests/payment.test.ts
🗂️

Plan multi-step work

Breaks big requests into a tracked task list, works through each step, and keeps you posted.

TaskCreate(subject="Add password reset flow")
  → 1. Create reset token model
  → 2. Add /reset-request endpoint
  → 3. Send email w/ token
  → 4. Add /reset-confirm endpoint
  → 5. Write tests
🚀

Build features end-to-end

From spec to working code: models, routes, UI, tests — wired together and verified.

// "Add a dark-mode toggle"
Write("src/theme.ts", themeStore)
Edit("src/Header.tsx", addToggle)
Bash("npm run build")  # ✓ build ok
Bash("npm test")      # ✓ 18 passed
🐛

Fix bugs

Reproduces, traces the root cause across files, patches it, and confirms the fix with a test.

# bug: cart total off by one tax step
Read("src/cart/total.ts")
Edit(..., new_string="applyTax(subtotal)")
Bash("npm test cart")  # ✓ fixed
